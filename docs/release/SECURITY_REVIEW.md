# 候选版本安全审查

审查范围：本地候选分支相对于 `9c97d5c282b2d4c55d3a54305ce5b85e9272e109` 的代码与隔离 Mock 测试。它不是渗透测试，也不构成法律合规证明。

| 项目 | 证据与当前状态 | 剩余风险 |
| --- | --- | --- |
| 认证 | `src/lib/auth/accounts.ts` 使用 Better Auth 邮箱验证、密码重置短期令牌、重置后撤销会话、数据库限流及单一受信任来源；E2E 覆盖注册、邮箱确认、登录和发送失败提示。 | 真实邮件投递、退信及公网 Cookie/CSRF 未验收。 |
| 数据隔离 | `getOwnedSession` 通过 ownerId 查询；会话 DELETE 也带 ownerId 条件。E2E 验证跨用户读取、发送、结束、报告与删除返回 404；反馈仅列出本人记录，管理员查询受已验证邮箱匹配控制。 | 尚无外部渗透测试；管理员邮箱配置与账号保护要由运营方维护。 |
| 数据删除与导出 | 账号删除触发器清除在线训练、场景及反馈；导出包含反馈。E2E 从隔离 SQLite 核对反馈删除。 | 备份、上游模型及邮件供应商留存不会自动同步删除，恢复历史备份可能重新引入已删除数据。须先确定运营流程与保留期限。 |
| 密钥与日志 | 模型 Key、邮件 Key 由服务端环境变量读取；`src/lib/ai/service.ts` 记录操作、状态、耗时、Token 与费用，不打印提示词、完整对话或 Key；`deploy/Caddyfile` 删除请求字段；`src/lib/auth/accounts.ts` 脱敏认证日志。 | 必须在真实容器与外部日志系统中检查实际输出及权限。 |
| 输入与费用 | Zod 校验场景、消息与反馈；模型输入、输出、速率、并发及每日/月度额度均由服务端限制。 | 费用零风险依赖供应商后台“免费额度用完即停”，详见 `AI_COST_PROTECTION.md`。 |
| 部署 | `Dockerfile` 使用非 root 用户，`compose.yaml` 对应用容器禁增权、删除 capability、只读根文件系统并挂载 SQLite 卷；Caddy 限请求体与 HTTPS 重定向。 | 本机无 Docker，当前 SHA 的 Linux 容器、证书、卷权限、恢复演练均未验证。 |
| 依赖 | 本轮 `npm audit` 为 11 个中危；`npm audit --omit=dev` 为 4 个中危，来自构建工具链 `drizzle-kit` / `esbuild`；独立 `deploy/runtime` 审计为 0。 | 锁文件的 omit 分类不等于最终镜像依赖，发布时仍需审查实际镜像/SBOM；未执行自动升级。 |

运营方和法律专业人士需审阅 [隐私说明](/privacy) 与 [测试版使用说明](/terms)：补齐运营主体、联系方式、数据处理地域、主库和备份保留期限、供应商删除流程、投诉与异常处理。当前文字不能替代正式法律文本。不得把真实客户隐私材料放入训练。
