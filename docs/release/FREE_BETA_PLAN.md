# 免费文字版受控测试计划

## 目标与范围

建议先邀请 5–10 名自愿参与者，分两批测试文字训练。人数是产品探索建议，不是统计显著性结论。先在隔离环境完成真实邮件、真实免费模型、小流量用量和备份恢复验证，再开放任何外部注册。语音、支付、正式能力认证均不纳入本轮。

## 参与者任务

1. 阅读测试说明及隐私提示，注册、验证邮箱并登录。
2. 用虚构客户资料选择系统模板或自建场景，创建训练，至少完成三轮对话。
3. 故意测试一次网络中断或回复失败后的重试，结束训练并阅读评分证据和改进建议。
4. 刷新并重新登录，检查历史记录、报告和训练额度；在手机上完成一场训练。
5. 使用反馈页提交问题或建议，并尝试数据导出；账号删除由愿意测试该流程的参与者自愿执行。

## 收集与判断

收集任务完成率、完成时间、失败步骤、可复现错误、客户重复或角色偏移、评分引用错误、主观有用性、移动端障碍、服务响应时间及每用户实际供应商 Token/账单。反馈页提醒不要提交真实客户资料或密钥。运营方按严重程度分组，优先修复越权、数据丢失、无法完成训练和错误计费。

继续开发的建议门槛：核心流程可独立完成；没有 P0/P1 数据与权限问题；评分引用逐条可核对；参与者能够指出至少一条具体可执行的改进建议；真实费用在事先核实的免费限额内。门槛需要运营方在测试前确认，当前没有真实用户样本，不能声称达成。

结束测试时应导出匿名汇总、检查备份及删除请求，并记录未解决问题。测试者须知明示 AI 评分局限和匿名/账号数据保存规则。
