## D. 云后台与 GitHub 操作

- 配置 Linux 防火墙，只向公网开放 80/443。SSH 由管理网络访问，CI 的 SSH 入口按组织选定的网络与审批策略配置。
- 在 DNS 后台添加正确的 A/AAAA 记录；没有 IPv6 的主机不添加 AAAA。在 Resend 添加发件域，按控制台值配置 SPF 和 DKIM，确认域通过验证，再创建只用于发信的密钥。测试注册和找回密码的真实投递及退信。 [Resend 发件域说明](https://resend.com/changelog/domain-claim)
- 在 GitHub 创建 `production` environment，限制 `main`，配置 Required reviewers 和 Prevent self-review，并用无生产密钥的运行确认确实被拦截。如果仓库方案不支持该规则，保持自动发布未启用，使用有记录的人工主机审批。 [GitHub 部署审核说明](https://docs.github.com/en/actions/how-tos/deploy/configure-and-manage-deployments/review-deployments)
