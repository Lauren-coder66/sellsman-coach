# 部署与运维记录

当前尚未部署预发布或生产环境。本页记录现有运行方式和待验证的部署方案。

## 本地

安装项目锁定依赖后，配置独立测试库。普通回归使用 Mock；真实验收使用已验证的北京百炼配置和测试语料。环境变量参考项目根目录的 `.env.production.example`；该文件仅为模板。密钥由服务端运行环境注入。SQLite 默认在项目的数据目录，真实测试通过 `DATABASE_URL` 使用独立绝对路径。

## 待验证的生产方案

优先评估 Linux 单机、Docker、Next.js standalone、持久化卷、HTTPS 反向代理和独立备份。SQLite 不放在容器临时文件系统。多实例场景单独评估数据库迁移。实际月成本、备份恢复、回滚、健康检查、监控和 HTTPS 均待选定基础设施后实测；当前不具备生产发布凭证。
